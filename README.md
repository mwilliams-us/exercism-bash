## 🎯 Purpose

This repository serves as a **personal learning workspace** dedicated to developing practical Bash skills that complement broader programming and software development efforts across various languages.

## 🔄 Workflow

The general development loop follows these steps:

1.  **Analyze**: Read and thoroughly understand the exercise requirements.
2.  **Inspect**: Review the provided test suite to clarify expectations.
3.  **Implement**: Write the solution in Bash.
4.  **Execute**: Run the local Bats test suite.
5.  **Debug**: Iterate until all tests pass.
6.  **Commit**: Save the completed exercise to version control.

## 🧪 Testing

Exercises utilize **[Bats](https://github.com/bats-core/bats-core)** (Bash Automated Testing System).

To run tests from an exercise directory:

```bash
bats <exercise-name>.bats
```

**Example:**

```bash
cd exercises/practice/hello-world
bats hello_world.bats
```
